# Better Command History - v1.0.1
## Suggestion Fixes
### PLUGIN FIXES
**Suggestion lists**: Up and Down move through an open suggestion list again, as in vanilla, instead of jumping to history.
**Mid-line editing**: With the cursor in the middle of your text, Up and Down behave as in vanilla.
### PLUGIN UPDATES
**Shift for history**: Hold Shift with Up or Down to browse history while several suggestions are open. A list with a single suggestion still lets the arrows browse history.
